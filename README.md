# WhatsApp Wrapped

Statistiche e premi di una chat WhatsApp, calcolati nel browser a partire dal file esportato (.txt o .zip). Sito statico, senza backend: https://strumentigratisitalia.github.io/whatsapp-wrapped/

- `parser.js` legge l'esportazione (Android/iPhone, it/en, zip incluso)
- `stats.js` calcola statistiche e premi
- `app.js` interfaccia, grafici e immagini da condividere
- `demo.js` chat di esempio

Non affiliato a WhatsApp o Meta.
